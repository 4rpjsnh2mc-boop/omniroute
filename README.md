# Тендерный калькулятор

Веб-приложение для расчёта тендеров: позиции, себестоимость, налоги РФ 2026 года,
обеспечение, маржа и цена для торгов. Работает на вашем сервере, без VPN и без
платных сервисов. У каждого сотрудника свой логин и свои тендеры; прайс общий.

## Что умеет

- Загружает закупку по ссылке (ЕИС zakupki.gov.ru, Росэлторг, B2B-Center и похожие):
  предмет, заказчик, НМЦК, сроки, обеспечение, аванс, позиции с количествами.
- Скачивает открытые документы закупки (ТЗ, проект контракта, обоснование НМЦК)
  и хранит их на сервере. Для файлов, которые площадка отдаёт только после входа,
  показывает список: их можно скачать вручную и загрузить в тендер.
- Считает налоги 2026 года: ОСНО (НДС 22% с вычетом, налог на прибыль 25%),
  УСН «доходы» 6% и «доходы минус расходы» 15% с НДС 0, 5, 7 или 22%.
- Показывает чистую прибыль, маржу, безубыточную цену, цену при целевой марже,
  шаги снижения на торгах и антидемпинг по ст. 37 44-ФЗ.
- Прайс компании: цены подставляются в позиции по названию.

## Установка

На сервере с Ubuntu 22.04 или 24.04 выполните от root:

```
curl -fsSL https://raw.githubusercontent.com/4rpjsnh2mc-boop/omniroute/refs/heads/claude/ecstatic-lovelace-5myzzh/install.sh | sudo bash
```

Установщик спросит поддомен (можно пропустить) и пароль администратора.
Повторный запуск той же команды обновляет программу; данные не трогаются.

- Программа: `/opt/tender/app`
- Данные и документы: `/var/lib/tender` (ежедневные копии базы в `backups/`)
- Настройки: `/etc/tender.env`
- Служба: `systemctl status tender`, журнал: `journalctl -u tender -n 50`

## Для разработчика

Только стандартная библиотека Python 3.10+, без внешних зависимостей.

```
TENDER_ADMIN_PASSWORD=секрет python3 app/server.py create-admin admin
python3 app/server.py serve          # http://127.0.0.1:8090
python3 -m unittest discover tests   # тесты разбора площадок
```
