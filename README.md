# Тендерный калькулятор

Веб-приложение для расчёта тендеров: позиции, себестоимость, налоги РФ 2026 года,
обеспечение, маржа и цена для торгов. Работает на вашем сервере, без VPN и без
платных сервисов.

## Как устроен доступ

- Вы отправляете людям **ссылку-приглашение**. Человек открывает её, вводит имя
  и сразу работает. Регистрации и паролей нет.
- У каждого **своё рабочее место**: свои тендеры, свой прайс, свои налоговые настройки.
  Другие люди с той же ссылкой их не видят.
- Чтобы открыть свои тендеры на другом устройстве, человек берёт **личную ссылку**
  в разделе «Настройки».
- Без кода из ссылки-приглашения посторонний открыть калькулятор не может.

## Что умеет

- Загружает закупку по ссылке (ЕИС zakupki.gov.ru, Росэлторг, B2B-Center и похожие):
  предмет, заказчик, НМЦК, сроки, обеспечение, аванс, позиции с количествами.
- Скачивает открытые документы закупки и хранит их на сервере. Для файлов, которые
  площадка отдаёт только после входа, показывает список, их можно загрузить вручную.
- Налоги 2026 года: ОСНО (НДС 22% с вычетом, налог на прибыль 25%),
  УСН «доходы» 6% и «доходы минус расходы» 15% с НДС 0, 5, 7 или 22%.
- Чистая прибыль, маржа, безубыточная цена, цена при целевой марже, шаги снижения
  на торгах, антидемпинг по ст. 37 44-ФЗ.
- Свой прайс у каждого: цены подставляются в позиции по названию.

## Установка

На сервере с Ubuntu 22.04 или 24.04 выполните от root:

```
curl -fsSL https://raw.githubusercontent.com/4rpjsnh2mc-boop/omniroute/refs/heads/claude/ecstatic-lovelace-5myzzh/install.sh | sudo bash
```

В конце установщик покажет ссылку-приглашение. Повторный запуск той же команды
обновляет программу; данные не трогаются.

Команды на сервере:

- `tender-link` — показать ссылку-приглашение
- `tender-link new` — выпустить новую (старая перестанет пускать новых людей)
- `tender-link users` — список рабочих мест
- `tender-link user N` — новая личная ссылка для рабочего места N, если человек её потерял

Где что лежит: программа `/opt/tender/app`, данные и документы `/var/lib/tender`
(ежедневные копии базы в `backups/`), настройки `/etc/tender.env`,
служба `systemctl status tender`, журнал `journalctl -u tender -n 50`.

## Для разработчика

Только стандартная библиотека Python 3.10+, без внешних зависимостей.

```
TENDER_INVITE=test python3 app/server.py serve   # http://127.0.0.1:8090/#/join/test
python3 -m unittest discover tests                # тесты разбора площадок
```
