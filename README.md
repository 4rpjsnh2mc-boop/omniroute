# Тендерный калькулятор

Веб-приложение для расчёта тендеров: позиции, себестоимость, налоги РФ 2026 года,
обеспечение, маржа и цена для торгов. Работает на вашем сервере, без VPN и без
платных сервисов.

## Как устроен доступ

- Вы отправляете людям **ссылку-приглашение**. Человек открывает её, вводит имя
  и сразу работает. Регистрации и паролей нет.
- У каждого **своё рабочее место**: свои тендеры, свой прайс, свои налоговые настройки.
  Другие люди с той же ссылкой их не видят.
- Чтобы открыть свои тендеры на другом устройстве, человек берёт **личную ссылку**
  в разделе «Настройки».
- Без кода из ссылки-приглашения посторонний открыть калькулятор не может.

## Что умеет

- Загружает закупку по ссылке (ЕИС zakupki.gov.ru, Росэлторг, B2B-Center и похожие):
  предмет, заказчик, НМЦК, сроки, обеспечение, аванс, позиции с количествами.
- Скачивает открытые документы закупки и хранит их на сервере. Для файлов, которые
  площадка отдаёт только после входа, показывает список, их можно загрузить вручную.
- Если площадка не пускает без входа: закупку можно разобрать по скриншотам и фото страницы
  (Ctrl+V прямо на странице), по ТЗ в PDF или Word или по скопированному тексту страницы.
  Калькулятор распознаёт номер, предмет, заказчика, ИНН, НМЦК, сроки, обеспечение, аванс,
  позиции с количеством и ценой и отметки вроде «эквивалент не допускается».
- Налоги 2026 года: ОСНО (НДС 22% с вычетом, налог на прибыль 25%),
  УСН «доходы» 6% и «доходы минус расходы» 15% с НДС 0, 5, 7 или 22%.
- Чистая прибыль, маржа, безубыточная цена, цена при целевой марже, шаги снижения
  на торгах, антидемпинг по ст. 37 44-ФЗ.
- Свой прайс у каждого: цены подставляются в позиции по названию, а если позиции нет,
  калькулятор предлагает похожие из прайса (аналоги), когда заказчик допускает эквивалент.
- Прайс можно загрузить как угодно: вручную, файлом Excel, Word, PDF, CSV или архивом,
  скриншотом (Ctrl+V прямо на странице) или фото с телефона, ссылкой на Яндекс.Диск,
  Google Таблицы, Google Документы, Google Диск, Dropbox или страницу прайса на сайте,
  либо вставить текст из письма или мессенджера. Перед добавлением показывается таблица
  для проверки: что добавится, что обновится, лишнее можно снять галочкой.
- Цены конкурентов из открытых данных ЕИС: цена за единицу в заключённых контрактах
  по региону тендера и по России, кто поставлял, история закупок заказчика.
- Рекомендуемая цена: чуть ниже конкурентов, но не ниже минимальной маржи и не выше НМЦК.
  Решение принимает человек.
- Подводные камни: «эквивалент не допускается», только для СМП, нацрежим, образцы, монтаж,
  разгрузка, поставка партиями, штрафы, короткий срок, долгая оплата, отмены у заказчика.
- Справка: кратко о коммерческих закупках, 223-ФЗ, 44-ФЗ и капремонте (615-ПП), каталог
  площадок (федеральные, коммерческие, корпоративные, малые закупки, агрегаторы) с поиском
  по всем сразу и отметкой «я здесь зарегистрирован».
- Работа с тендером: метки этапов («Проверить тендер», «Подать заявку на площадке» и др.),
  «важный», заметка, сводка одним текстом, напоминания (на главной, в Telegram и в календаре
  телефона), фильтры списка по этапу, статусу и сроку.

## Установка

На сервере с Ubuntu 22.04 или 24.04 выполните от root:

```
curl -fsSL https://raw.githubusercontent.com/4rpjsnh2mc-boop/omniroute/refs/heads/claude/ecstatic-lovelace-5myzzh/install.sh | sudo bash
```

Установщик спросит поддомен и, по желанию, токен Telegram-бота для напоминаний
(бота создают бесплатно в @BotFather). В конце он покажет ссылку-приглашение. Повторный запуск той же команды
обновляет программу; данные не трогаются.

Ещё установщик предложит поставить встроенный браузер Chromium (около 500 МБ). Он нужен
площадкам, которые показывают закупку только с JavaScript, например Bidzaar. Если вы
отказались, а потом передумали: удалите строку `TENDER_RENDER=` из `/etc/tender.env`
и запустите установку ещё раз.

Команды на сервере:

- `tender-link` — показать ссылку-приглашение
- `tender-link new` — выпустить новую (старая перестанет пускать новых людей)
- `tender-link users` — список рабочих мест
- `tender-link user N` — новая личная ссылка для рабочего места N, если человек её потерял

Где что лежит: программа `/opt/tender/app`, данные и документы `/var/lib/tender`
(ежедневные копии базы в `backups/`), настройки `/etc/tender.env`,
служба `systemctl status tender`, журнал `journalctl -u tender -n 50`.

## Для разработчика

Только стандартная библиотека Python 3.10+, без внешних зависимостей. Для прайсов со
скриншотов и из PDF нужны программы `tesseract-ocr tesseract-ocr-rus poppler-utils imagemagick`
(установщик ставит их сам).

```
TENDER_INVITE=test python3 app/server.py serve   # http://127.0.0.1:8090/#/join/test
python3 -m unittest discover tests                # тесты разбора площадок
```
